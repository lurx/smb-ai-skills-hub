# אסטרטגיות הצעות מחיר (Bidding Strategies)

**מטרה**: עצי החלטה לבחירת אסטרטגיית bidding בכל פלטפורמה, ותנאי מעבר בין אסטרטגיות לפי מספיקות דאטה.
**גרסה**: 1.0 | **נבדק**: 2026-09
מותקן אל `ads/references/bidding-strategies.md` בתיקיית העסק. משמש את `ads-budget` ואת סקילי הפלטפורמות.

> שמות האסטרטגיות נכונים ל-2026-09; ראו `standards/platform-specs.md` אם משהו לא מופיע בממשק.

## עקרונות רוחב

1. **דאטה קודמת לאוטומציה**: אסטרטגיות יעד (tCPA, tROAS, Cost Cap) עובדות רק עם נפח המרות מספק. מתחת לסף — האלגוריתם מנחש.
2. **סולם הדרגתי**: קליקים → המרות → יעד CPA → יעד ROAS. לא מדלגים שלבים.
3. **מעבר אחד בכל פעם**: שינוי אסטרטגיה מאפס learning phase. לא משנים במקביל תקציב, קהל ואסטרטגיה.
4. **יעד ריאלי בכניסה**: בהגדרת tCPA/tROAS ראשונה, קבעו יעד לפי הממוצע בפועל ב-30 הימים האחרונים (לא לפי השאיפה), והדקו בצעדים של 10-15%.

## Google Ads

```
התחלה
├─ <30 המרות/חודש?
│  └─ Maximize Clicks (עם תקרת CPC ברמת הבנצ'מרק)
│     └─ כשעוברים 30 המרות/חודש → Maximize Conversions
├─ 30-50 המרות/חודש?
│  └─ Maximize Conversions (ללא יעד)
│     └─ כש-CPA מתייצב (סטייה שבועית <20% במשך 2-3 שבועות) → Target CPA (tCPA)
├─ >50 המרות/חודש?
│  └─ Target CPA
│     └─ כשמעקב הכנסות (revenue tracking) פעיל ואמין → Target ROAS (tROAS)
└─ מעקב הכנסות פעיל + >50 המרות/חודש?
   └─ Target ROAS
      ├─ e-commerce עם ערכי עסקה משתנים → tROAS עדיף על tCPA
      └─ לידים בערך אחיד → הישארו ב-tCPA
```

- **קמפייני Brand**: Target Impression Share (מיקום עליון, ≥90%) — לא tCPA.
- **PMax**: מתחיל Maximize Conversions; הוסיפו יעד רק אחרי ≥30 המרות בקמפיין עצמו.
- **AI Max for Search**: רלוונטי רק לחשבונות עם מעקב המרות בשל והיסטוריית מילות מפתח; מחייב רשימות שליליות חזקות (רשת רחבה יותר).
- **Portfolio bidding**: אחדו קמפיינים דלי-המרות תחת אסטרטגיית תיק אחת כדי לצבור דאטה משותפת.

## Meta Ads

```
התחלה (רמת ad set / קמפיין)
├─ <50 המרות/שבוע ל-ad set?
│  └─ Highest Volume (ברירת המחדל, לשעבר Lowest Cost)
│     ├─ צפו לשונות ב-CPA — זה מחיר איסוף הדאטה
│     └─ ABO (תקציב ברמת ad set) לשלב הבדיקות
├─ ≥50 המרות/שבוע + CPA יציב אך גבוה מהיעד?
│  └─ Cost Cap (תקרת CPA = היעד ×1.1, הדקו בהדרגה)
│     └─ אם הנפח צונח >30% → העלו את התקרה 10% או חזרו ל-Highest Volume
├─ ≥50 המרות/שבוע + צורך בשליטה מקסימלית (מכרזים תחרותיים, LTV ידוע)?
│  └─ Bid Cap (הצעה מקסימלית פר מכרז — למתקדמים בלבד, דורש ניטור יומי)
└─ e-commerce עם מעקב ערך רכישה?
   └─ ROAS Goal (בתוך Advantage+ Sales כשיש נפח)
```

- **CBO מול ABO**: ABO לבדיקות (שליטה בחלוקה בין קהלים); CBO לקמפיינים מוכחים (האלגוריתם מחלק). מעבר ל-CBO רק אחרי שה-ad sets המנצחים זוהו.
- **Advantage+ Bidding**: בקמפייני Advantage+ Sales ההקצאה בין placements אוטומטית — שלבו עם טירגוט רחב ונפח קריאייטיב גבוה.

## TikTok Ads

```
התחלה (רמת ad group)
├─ תקציב learning < פי 50 מ-CPA היעד?
│  └─ עצרו — הגדילו תקציב או אחדו ad groups לפני בחירת אסטרטגיה
├─ שלב איסוף דאטה (טרם 50 המרות ל-ad group)?
│  └─ Lowest Cost (מקסימום המרות בתקציב)
├─ ≥50 המרות ל-ad group + CPA תנודתי?
│  └─ Cost Cap (תקרת CPA = היעד; TikTok נוטה לספק מתחת לתקרה)
├─ שליטה פר-אימפרסיה (נדיר)?
│  └─ Bid Cap
└─ רוצים אוטומציה חלקית?
   └─ Smart+ עם Modular Control — נעלו ידנית טירגוט/קריאייטיב/תקציב לפי הצורך,
      השאירו את השאר לאלגוריתם
```

- אל תערכו ad group ב-learning phase (עריכה מאפסת אותו).
- קריאייטיב הוא ה-bidding האמיתי ב-TikTok: לפני החלפת אסטרטגיה, בדקו אם הבעיה היא fatigue (CTR <0.5% אחרי 3 ימים → החליפו קריאייטיב, לא אסטרטגיה).

## LinkedIn Ads

```
התחלה
├─ קמפיין חדש / <15 המרות/חודש?
│  └─ Manual CPC — נקודת פתיחה מומלצת לשליטה בעלויות
│     └─ הצעה התחלתית: הטווח המומלץ של הפלטפורמה, בקצה הנמוך
├─ 15+ המרות/חודש + CPA ידוע?
│  ├─ צורך ב-CPA צפוי → Cost Cap (או Target Cost)
│  └─ צורך בנפח מקסימלי + דאטה מבוססת → Maximum Delivery
│     └─ היקרה ביותר — רק לסקיילינג על קהל מוכח, לעולם לא לקמפיין חדש
└─ Message/Conversation Ads?
   └─ Cost Per Send (CPS)
```

- LinkedIn יקרה מבנית: Manual CPC כברירת מחדל שמרנית, ועברו לאוטומציה רק כשיש בסיס דאטה. מעבר מוקדם מדי ל-Maximum Delivery הוא הדרך המהירה לשרוף תקציב B2B.

## Microsoft Ads

```
התחלה (בדרך כלל אחרי Google Import)
├─ מייבאים מ-Google?
│  ├─ הורידו הצעות 20-35% (אל תייבאו bids כמו שהם — CPC זול יותר ב-Bing)
│  ├─ ודאו שהאסטרטגיה המיובאת קיימת ב-Microsoft (לא כל אסטרטגיות Google מתורגמות;
│  │   יעדי tCPA/tROAS לא תמיד עוברים בשלמות — בדקו אחרי הייבוא)
│  └─ בדקו הגדרות syndication (Audience Network עלול להתווסף בייבוא)
├─ <15 המרות/30 יום?
│  └─ Manual CPC (שימו לב: Enhanced CPC הוצא משימוש ב-Google ב-2025 —
│     ודאו זמינות ב-Microsoft לפני שממליצים)
├─ ≥15 המרות/30 יום?
│  └─ Target CPA (יעד נמוך מהמקביל ב-Google — נצלו את יתרון ה-CPC)
└─ מעקב הכנסות + נפח מספק?
   └─ Target ROAS
```

- כלל אצבע: שקפו את מדרגת האסטרטגיה של Google עם פיגור שלב אחד (הנפח ב-Microsoft קטן, הדאטה מצטברת לאט יותר).

## מתי לעבור אסטרטגיה — ספי מספיקות דאטה

### תנאים לעלייה במדרגה (לכיוון אוטומציה/יעד)

| מעבר | סף דאטה מינימלי |
|------|------------------|
| Clicks → Conversions (Google) | ≥30 המרות/חודש |
| Max Conversions → tCPA (Google) | ≥30-50 המרות/חודש + CPA יציב (סטייה <20% במשך 2-3 שבועות) |
| tCPA → tROAS (Google/Microsoft) | ≥50 המרות/חודש + מעקב הכנסות אמין ≥30 יום |
| Highest Volume → Cost Cap (Meta) | ≥50 המרות/שבוע ל-ad set |
| Lowest Cost → Cost Cap (TikTok) | ≥50 המרות ל-ad group (יציאה מ-learning) |
| Manual CPC → Cost Cap / Max Delivery (LinkedIn) | ≥15 המרות/חודש |
| Manual → tCPA (Microsoft) | ≥15 המרות/30 יום |

### תנאים לירידה במדרגה (חזרה לשליטה ידנית/רחבה)

- הנפח צנח >30% תוך שבוע אחרי הידוק יעד → הרפו את היעד 10-15% לפני שמוותרים על האסטרטגיה.
- הקמפיין נתקע ב-learning limited >שבועיים → רדו מדרגה או אחדו מבנה (פחות ad sets, יותר דאטה לכל אחד).
- ירידת נפח עונתית שהורידה את החשבון מתחת לספים → חזרו זמנית למדרגה הקודמת.

### היגיינת מעברים

- אחרי כל מעבר: המתינו learning phase מלא (בדרך כלל 1-2 שבועות או 50 אירועי המרה) לפני שיפוט.
- תעדו כל מעבר בדוח (`BUDGET-STRATEGY-REPORT.md`) עם התאריך, הסיבה והסף שהצדיק אותו.
- בביקורת: אסטרטגיית יעד הפועלת מתחת לסף הדאטה שלה = ממצא WARNING; Manual/Volume בחשבון שמזמן עבר את הסף = ממצא Medium (הזדמנות אופטימיזציה).
