# Meta Ads — רשימת ביקורת מלאה (50 בדיקות)

מדריך ייחוס לביצוע ביקורת עומק על חשבון Meta Ads (Facebook + Instagram): 50 בדיקות בארבע קטגוריות משוקללות.
גרסה: 1.0 | נבדק: 2026-09

> **הערה על עדכניות**: המתודולוגיה כאן היא evergreen — ספים, שיטות בדיקה וסדרי עדיפויות. עובדות פלטפורמה שמשתנות (סוגי קמפיינים, מפרטי פורמטים, גרסאות API, זמינות פיצ'רים) נשמרות בקבצי `standards/` — בכל מקום שבדיקה תלויה בעובדה כזו, מופיעה הפניה מפורשת.

## איך להשתמש בקובץ הזה

- תהליך הביקורת, סולם הציונים (A-F), פורמט ה-Health Score, הגדרות עדיפויות ו-Quick Wins — הכול לפי `ads/references/audit-process.md`. הקובץ הזה מכיל רק את הבדיקות עצמן.
- כל בדיקה: **מה בודקים** (השדה/הדוח המדויק — מנוסח כך שניתן להריץ עם Meta MCP או ידנית ב-Ads Manager / Events Manager), **ספים** (PASS / WARNING / FAIL עם מספרים), **תיקון מומלץ**, **עדיפות**.
- בדיקה לא רלוונטית (למשל קטלוג בחשבון לידים) — מדלגים ומציינים למה, לפי התהליך המשותף.
- חלון נתונים ברירת מחדל: 30 הימים האחרונים, אלא אם צוין אחרת בבדיקה.

## Pixel / CAPI Health (30%) — M01–M13

תקינות המדידה קודמת לכל דבר אחר: בלי דאטה אמין, כל שאר הביקורת חשודה. אם M01 או M02 נכשלות — לסמן את כל הדוח כ"מבוסס על דאטה חלקי".

### M01 | התקנת Meta Pixel

| | |
|---|---|
| מה בודקים | Events Manager → Data Sources → Pixel: סטטוס Active ואירועי PageView נכנסים מכל דפי האתר המרכזיים (דף בית, מוצר, עגלה, checkout, תודה). אימות עם Test Events או Pixel Helper. |
| ספים | PASS: פיקסל פעיל ויורה בכל הדפים · WARNING: פעיל אך חסר בחלק מהדפים · FAIL: לא מותקן / לא פעיל / אירועים לא נכנסו ב-48 השעות האחרונות |
| תיקון מומלץ | להתקין את הפיקסל דרך base code או אינטגרציית פלטפורמה (Shopify, GTM) בכל תבניות הדפים. |
