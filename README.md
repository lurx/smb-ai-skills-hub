# SMB AI Skills Hub

<div dir="rtl">

מאגר הסקילים הרשמי של Agentic OS — סקילים ל-Claude Code לעסקים קטנים ובינוניים, בעברית.
הסקילים מותקנים לתוך תיקיית העבודה של העסק (כל התקנה היא עותק שבבעלות המשתמש).

## התקנה

דרך אפליקציית Agentic OS (מאגר המיומנויות), או ידנית: העתיקו את תיקיית הסקיל אל
`.claude/skills/` בתיקיית העבודה.
