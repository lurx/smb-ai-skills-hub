## `check-cuts.py`

מודד RMS בחלון חד־צדדי בכל נקודת חיתוך.

```bash
python3 scripts/check-cuts.py        # כל הרילסים
python3 scripts/check-cuts.py 05     # רילס אחד
```

**סף:** `rms > 0.035` על חלון של 40ms = דיבור. נמדד מול פודקאסט אמיתי — רווחים
בין מילים יושבים על `0.001–0.03`, דיבור רץ על `0.05–0.20`. **לכייל מחדש להקלטה
שקטה או רועשת יותר.**

## `npm test`

### חורים — לעבור על כל פריים, לא לדגום

```ts
for (const seg of config.body) {
  for (let i = 0; i < segmentFrames(seg); i++) {
    const t = seg.start + i / fps;
    if (!activeBlock(beats, t)) gaps.push(...);
  }
}
```

החור הראשון שנמצא בפרויקט המקורי היה **5 פריימים** — 0.2 שניות. contact sheet
שדוגם כל 2 שניות לא היה מוצא אותו לעולם.

### הבלוק האחרון כולל את הקצה שלו

הפריים האחרון של רילס נוחת בדיוק על `end` של הבלוק האחרון. טווח חצי־פתוח
משאיר אותו בלי כתובית.

```ts
const isLast = i === blocks.length - 1;
if (t >= b.lines[0].t && (isLast ? t <= b.end : t < b.end)) return b;
```

### בדיקות נוספות ששוות את המקום

- כל בלוק יושב **בתוך** קטע שנשמר (אחרת הוא מכתב דיבור שנחתך)
- הקולד־אופן נשאב מתוך קטע שנשמר
- מה שעל המסך בפריים האחרון של כל קטע — לא ריק, וגם נשמע
- אף שורה לא רחבה מספיק כדי להרוס את היררכיית הגדלים

## בדיקה ויזואלית

```bash
npx remotion still Reel05 /tmp/x.png --frame=300

FF=$(python3 -c "import imageio_ffmpeg;print(imageio_ffmpeg.get_ffmpeg_exe())")
"$FF" -y -i out/reel-05.mp4 -vf "fps=1,scale=150:267,tile=11x4" -frames:v 1 /tmp/sheet.png
```

**ואז לפתוח את התמונה ולהסתכל בה.** דגימה של פריים לשנייה מספיקה כדי לראות
פריסה, גלישה, וצבעים — אבל לא כדי למצוא חורים.

## אימות אודיו

```bash
"$FF" -i out/reel.mp4 -af volumedetect -f null - 2>&1 | grep volume
```

**קיום ערוץ אודיו אינו קיום צליל.** בפרויקט המקורי אישרתי ״יש stream אודיו״
ועברתי הלאה; הקובץ היה תקין, אבל לא בדקתי שהנגן בכלל מסוגל להגיש אותו.

**רמה טיפוסית:** `-24dB` ממוצע לפודקאסט. רשתות מכוונות לסביבות `-14 LUFS`,
אז שווה לנרמל לפני פרסום.

## ⚠️ מה שרק אוזן תופסת

1. **חיתוך בתוך עיצור פוצץ** — ק ת ב פ. הסגירה נראית כמו שקט.
2. **האם נקודת חיבור נשמעת כמשפט אחד** — אפשר לקרוא את הטקסט ולנחש, אבל רק
   האזנה מכריעה.
3. **קצב** — האם הכתוביות מדביקות את הדיבור.

בפרויקט שממנו נולד הסקיל הזה, **שתי התקלות החמורות ביותר נתפסו בהאזנה של
הלקוח, אחרי שכל הבדיקות היו ירוקות.**

> בדיקות ירוקות אינן אישור. הן רק אומרות שמחלקה מסוימת של תקלות נשללה.
