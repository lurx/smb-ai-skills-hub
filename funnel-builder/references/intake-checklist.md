# רשימת הראיון — מה לשאול ולוודא בכל שלב

זה הלב של הסקיל. הסוכן עובר שלב-שלב, שואל בשפה פשוטה, מוודא שיש את מה שצריך, ומשלים אם חסר. **סמן ✅ רק כשהשלב סגור.** אל תעבור הלאה בלי זה.

טיפ: שאל **שאלה אחת בכל פעם**. אם בעל העסק לא בטוח — הצע ברירת מחדל ("רוב העסקים כמוך הולכים על X, מתאים?") והמשך. אל תציף אותו ב-10 שאלות בבת אחת.

---

## שלב 1 — המוצר והמטרה
- [ ] מה בדיוק מוכרים? (מוצר/שירות/קורס/סדנה)
- [ ] מי בעל העסק / שם המותג / לוגו?
- [ ] מה מחיר הבסיס, ומה טווח המחירים?
- [ ] **פעולת ההמרה** — מה הלקוח יעשה בסוף? (בחר אחת: וואטסאפ עם בעל העסק / שריון בתשלום / תיאום שיחה / רכישה ישירה)
- [ ] ✅ *וודא:* יש **מטרה אחת** ברורה. שתי מטרות = לפצל לשני פאנלים.

## שלב 2 — הקהל וההתנגדות
- [ ] מי הלקוח האידיאלי? (גיל, מגדר, מצב, מה מניע אותו)
- [ ] מה **ההתנגדות מס' 1** שעוצרת קנייה? (מחיר / זמן / אמון / מרחק / התלבטות / "אחשוב על זה")
- [ ] מה הלקוח באמת רוצה שירגיש בסוף? (התוצאה הרגשית, לא רק הפיזית)
- [ ] ✅ *וודא:* יש התנגדות מרכזית **אחת** מוגדרת — כל השאלון והקופי יפרקו אותה. אם בעל העסק עונה "כל התשובות", אל תיתקע: הצע לו את זו שהכי מתאימה למוצר ולמחיר, הסבר למה, ובקש אישור.

## שלב 3 — השאלות
- [ ] אילו 4-6 שאלות? לכל שאלה קבע: **מסננת איכות** או **משנה הצעה** (או שתיהן).
- [ ] לכל שאלה: אילו 3-5 אופציות תשובה? emoji לכל אחת?
- [ ] יש שאלה מותנית? (למשל גיל רק אם בחרו "יום הולדת") — סמן את כלל הדילוג.
- [ ] **סדר את השאלות בקשת רגשית עולה.** ראה `copy-and-design.md`. בקצרה: שאלה 1 קלה ונעימה (על מה שהוא *רוצה*), אחר כך עובדתי, ורק בשאלה 3-4 נוגעים בכאב. מיד אחרי שאלת הכאב — שאלה שמרימה אותו חזרה, כדי שיגיע לטופס עם תקווה ולא עם כובד.
- [ ] ✅ *וודא:* אין שאלה מיותרת. **אין אופציית "רק בודק/מתעניין"** (יוצרת לידים בלי כוונה). "גמיש/עדיין סוגר" — כן, מסמן כוונה בלי לחץ.

## שלב 4 — ההצעה והתמחור
- [ ] איך המחיר משתנה לפי התשובות? (טבלת מחירים: לכל מסלול regular+special)
- [ ] יש **מחיר עוגן** להראות מחוק לצד המיוחד? (עוגן מגדיל תפיסת ערך)
- [ ] **יש הטבה / מתנה / בונוס?** (מתנה לנרשם, פריט נוסף, הנחה מוקדמת) — שאל מפורשות.
- [ ] יש מוצר המשך? אם כן, **האם התשלום הזה מתקזז ממנו?** קיזוז מלא מוחק את הסיכון ומרים המרה משמעותית.
- [ ] מה **כלול** בהצעה? (רשימת benefits קצרה)
- [ ] ✅ *וודא:* ההצעה **מותאמת אישית** — נגזרת מהתשובות, לא מחיר אחיד.

## שלב 5 — אמון והוכחה חברתית
- [ ] **יש עדויות / ביקורות?** (טקסט, צילומי מסך, וידאו) — שאל מפורשות.
- [ ] יש **מספרים** מרשימים? (כמות לקוחות, דירוג כוכבים, שנות ניסיון)
- [ ] יש **תמונות אמיתיות** של המוצר / התוצאה / התהליך / בעל העסק?
- [ ] ✅ *אם אין עדויות:* השתמש במונים כלליים ("מאות לקוחות"), אחריות, ניסיון, תמונות מוצר. **לעולם אל תמציא עדות מזויפת עם שם אמיתי.**
- [ ] ✅ *כלל אמינות:* אל תטען שהעדויות אמיתיות. תגיות "לקוח מאומת" או כותרת שמתגוננת מפני ספקנות רק מוכיחות שיש ממה לחשוד. תשים את צילומי המסך הגולמיים ותיתן לאנשים להחליט.

## שלב 6 — הצעד הסוגר
- [ ] **יש לינק שריון/תשלום?** — אם כן: סכום? מתקזז מהמחיר? נועל ל-24ש'?
- [ ] **יש קופון?** (קוד + הנחה + תוקף)
- [ ] **לאן הליד נכנס?** (וואטסאפ עם בעל העסק / רשימת דיוור / בסיס נתונים / CRM)
- [ ] יש דף תודה / סדרת מיילים אחרי? (דפי תוצאה אישיים + נרצ'ר במייל)
- [ ] ✅ *וודא חוקי ברזל:* מחיר נחשף רק אחרי לכידת ליד; השרת לא מודיע ללקוח; טלפון לא-תקין חסום.

## שלב 7 — קופי ועיצוב
- [ ] טון המותג? (חם/מקצועי/צעיר/יוקרתי)
- [ ] לוגו + צבעים + גופן?
- [ ] ✅ *וודא:* כל שאלה ו-CTA כתובים **אנושי**. עיצוב עקבי, RTL, מובייל-first, נגיש. ראה `copy-and-design.md`.

## שלב 8 — בנייה, מדידה, השקה
- [ ] Scaffold + מילוי קונפיג.
- [ ] אנליטיקס `funnel_events` מחווט בכל שלב.
- [ ] יעד הליד מחובר.
- [ ] מעבר CRO checklist (`cro-rules.md`).
- [ ] `tsc --noEmit` ירוק → build עובר → deploy.
- [ ] ✅ אחרי 3-4 ימים: ניתוח נטישה + החלטת איטרציה.

## תובנות ספציפיות-למוצר (שאל לפי הסוג)

| סוג מוצר | מה לשאול/לוודא במיוחד |
|---|---|
| **סדנה/אירוע** | מיקום (אצל הלקוח/אצלך), כמות משתתפים (מזיז מחיר למשתתף), תאריך/דחיפות, מסלול ילדים? |
| **קורס/דיגיטלי** | רמה/נקודת התחלה, מטרה אישית → **דף תוצאה מותאם** + **סדרת מיילים**, קופון להשקה |
| **שירות/ייעוץ** | פורמט (זום/פרונטלי), אורך המפגש, האם זו שיחת אבחון שמובילה לתהליך, תקציב, לוח זמנים, מי מקבל ההחלטה |
| **מוצר פיזי** | וריאנט/מידה/כמות, משלוח, מלאי/דחיפות |

## מלכודות שכדאי להכיר מראש
- בעל עסק "לא בטוח" על מחיר עוגן → הצע לגזור מהמחיר המלא/המשוקלל. אל תיתקע.
- "אין לי עדויות" → זה בסדר, יש חלופות (מונים/אחריות). אל תדלג על שלב האמון לגמרי.
- בעל עסק רוצה 12 שאלות → החזר ל-4-6. כל שאלה נוספת מפילה השלמה.
- בעל עסק פותח בשאלה הכי כואבת → **החזר אותו אחורה.** שאלה ראשונה כואבת = נטישה, כי עוד לא נבנתה השקעה שתחזיק אותו.
- "שהמערכת תשלח ללקוחות אוטומטית" → **לא**. השרת רק מודיע לבעל העסק; שליחה ללקוח = רק אחרי אישור אנושי.
