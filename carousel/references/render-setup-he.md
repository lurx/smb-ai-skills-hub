# הקמת סביבת הרינדור לקרוסלות — מדריך למשתמש

מדריך זה מיועד לבעל העסק. שני חלקים: Remotion (חובה, חינם) ו-Gemini
(אופציונלי, בתשלום קטן — בשבילו הקרוסלות מקבלות תמונות רקע שנוצרות ב-AI).

הוראות ההתקנה כתובות ל-Windows; פקודות macOS בסוגריים.

## חלק 1: Remotion (רינדור הטקסט והעיצוב) — חינם

Remotion חינמי לחלוטין לעסקים עד 3 עובדים, ללא הרשמה, ללא חשבון וללא מפתח
רישיון. (עסק עם יותר מ-3 עובדים צריך רישיון בתשלום מ-remotion.pro.)

1. התקינו Node (גרסה 18 ומעלה):
   - Windows: פתחו טרמינל והריצו `winget install OpenJS.NodeJS.LTS`
   - (macOS: `brew install node`)
2. את פרויקט ה-Remotion של הקרוסלות הסוכן יקים בשבילכם בתיקיית העסק בפעם
   הראשונה — אין צורך בהתקנה ידנית נוספת.

## חלק 2: מפתח Gemini (יצירת תמונות) — אופציונלי, בתשלום

בלי מפתח, הקרוסלות ירונדרו כעיצוב טקסטואלי בלבד — לגיטימי לחלוטין.
עם מפתח, כל שקף מקבל תמונת רקע/סצנה שנוצרת ב-AI (‎$0.05–0.15‎ לתמונה,
כלומר בערך ‎$0.5–1.5‎ לקרוסלה מלאה).

שימו לב: אין מסלול חינמי ליצירת תמונות ב-API — נדרשת טעינת קרדיט מראש
(מינימום בערך ‎$10, מספיק למאה שקפים ויותר).

1. היכנסו אל https://aistudio.google.com עם חשבון Google של העסק.
2. בתפריט בחרו **Get API key** ולחצו **Create API key**.
3. הפעילו חיוב: בלוח הבקרה בחרו **Billing** → הוסיפו כרטיס אשראי וטענו
   קרדיט מראש (מינימום ‎~$10). המסך באנגלית — התהליך הוא: הוספת אמצעי
   תשלום, בחירת סכום, אישור.
4. העתיקו את המפתח ושמרו אותו אצל הסוכן כשיתבקש. **לעולם אל תשלחו את
   המפתח במייל או תשמרו אותו בקובץ משותף.**

### כשנגמר הקרדיט

הסוכן יזהה זאת ויודיע לכם. טעינה חוזרת: aistudio.google.com → Billing.
היתרה המחייבת היא זו שמופיעה שם ב-**Dashboard → Usage and Limits**
(לפעמים יש פער סנכרון — מה שכתוב שם קובע).
