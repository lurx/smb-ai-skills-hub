# Brain Dump → Prompt

כלי שסורק את תיקיית הסקילים שלך (`~/.claude/skills/`), בונה קובץ HTML מותאם אישית, ופותח אותו בדפדפן.

המשתמש יוכל לכתוב בבלגן (בלי סדר, בעברית/אנגלית מעורבת), והכלי יסדר את זה לפרומפט חד עם זיהוי סקילים אוטומטי.

---

## מה לעשות כשמפעילים את הסקיל

### שלב 1: סריקת סקילים

סרוק את `~/.claude/skills/` ומצא את כל הסקילים המותקנים:

```bash
ls -d ~/.claude/skills/*/
```

לכל סקיל — קרא את `skill.md` או `SKILL.md` והוצא:
- שם הסקיל
- תיאור קצר
- מילות טריגר/מפתח

### שלב 2: שאלה למשתמש

```
🔍 מצאתי [X] סקילים בספרייה שלך.

רוצה/ה שאכלול את כולם בכלי?
[y] כן — כל הסקילים
[n] לא — רק בסיסיים (Claude Code core)
[c] תבחר/י ידנית
```

### שלב 3: בנה קובץ HTML מותאם

1. קרא את `template.html` מהתיקייה של הסקיל
2. החלף את `/*__SKILLS_INJECTION_POINT__*/` ב-JSON של הסקילים של המשתמש
3. פורמט:
```javascript
{
  'skill-id': {
    name: 'Skill Name',
    desc: 'קצר על מה הסקיל עושה',
    keywords: ['מילה1', 'מילה2', 'word1']
  },
  ...
}
```
4. שמור את הקובץ ב: `~/brain-dump.html`

### שלב 4: פתח בדפדפן

```bash
open ~/brain-dump.html
```

### שלב 5: הסבר קצר למשתמש

```
✅ הכלי מוכן ונפתח בדפדפן!

איך להשתמש:
1. כתוב/י בבלגן — בלי סדר, בעברית/אנגלית מעורבת
2. הכלי מזהה: הקשר / בקשה / מגבלות / שאלות / הלך רוח
3. מזהה את הסקילים הרלוונטיים שלך אוטומטית
4. מייצר פרומפט חד להעתקה

טיפ: שמור/י את הדף במועדפים. בכל פעם שירצי/תרצי לסדר מחשבות —
פשוט פתח/י ותכתוב/י.
```

## הערות טכניות

### חילוץ מילות מפתח מסקילים
אם `skill.md` לא מכיל מילות מפתח מפורשות, צור אותן אוטומטית מ:
- שם הסקיל
- תיאור הסקיל — מילות תוכן בולטות
- תרגם מונחים טכניים לעברית אם צריך

### פורמט מילות מפתח
- עברית ואנגלית ביחד (משתמשים ישראלים מערבבים)
- 3-7 מילים לכל סקיל
- מילים ייחודיות, לא גנריות

### תבנית ריקה
אם `~/.claude/skills/` לא קיים או ריק:
```
⚠️ לא מצאתי סקילים מותקנים.
פתחתי את הכלי בלי סקילים — תוכל/י עדיין להשתמש בזיהוי הקשר.
```

### עדכון הכלי
אם הסקיל כבר רץ פעם אחת וקיים `~/brain-dump.html`:
```
💡 הכלי כבר קיים. ליצור מחדש? [y/n]
```
