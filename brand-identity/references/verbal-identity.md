# Verbal Identity

## Voice attributes

Three or four, each written as a contrast pair. The contrast is what makes it
usable — "friendly" is unactionable, "friendly, not chummy" is a decision rule.

```
Direct, not blunt.
Warm, not cute.
Expert, not academic.
Confident, not boastful.
```

For each attribute, write:
- **What it means** — one sentence.
- **Do** — two concrete examples in the brand's actual context.
- **Don't** — two examples that fail, ideally near-misses rather than absurdities.

Near-misses do the work. Anyone can avoid the absurd failure.

## Tone range

Voice is constant; tone shifts with context. Map the range explicitly:

| Context | Tone | Notes |
|---|---|---|
| Marketing site | [most expressive end] | |
| Onboarding | | Reassuring, low-jargon |
| Product UI | [most restrained end] | Brevity over personality |
| Error states | | Never clever. Clever costs trust here |
| Support | | Accountable, no deflection |
| Incident comms | [flattest tone] | Facts, timeline, what's next |
| Social | | |

The error and incident rows matter most. Brands lose voice discipline exactly when
something has gone wrong, and that's when users are paying closest attention.

## Vocabulary

**Use** — the terms this brand commits to, especially where the category has
competing words. Pick one and stay consistent.

**Avoid** — filler and category clichés: *seamless, robust, leverage, revolutionary,
game-changing, best-in-class, effortless, delightful*. Also list any competitor-owned
term the brand shouldn't borrow.

**Never** — words with legal, regulatory, or trust implications. Domain-specific.

## Mechanics

Settle these once, in writing, or they drift:

- Person: first person plural, or brand-as-third-person?
- Contractions: yes, generally.
- Oxford comma: pick one.
- Sentence case or title case for headings and buttons.
- Capitalization of product and feature names.
- Numerals vs. words; date and time format.
- Emoji: where permitted, if anywhere.

## Messaging hierarchy

1. **Positioning statement** — internal, not customer-facing. The claim everything
   traces back to.
2. **Tagline** — external, five words or fewer if possible.
3. **Value propositions** — three, each addressing a distinct audience motivation.
4. **Proof points** — evidence under each proposition. If a proposition has no
   proof, it's an aspiration and should be cut or earned.
5. **Boilerplate** — the standard fifty-word description for press and partners.

## Test

Take three real sentences from the product or site, rewrite them in the defined
voice, and show before and after. If the rewrite isn't visibly different, the voice
definition is too generic to be useful — go back to the contrast pairs.
