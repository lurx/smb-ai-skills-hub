# Naming

## Generation

Work each mode deliberately rather than free-associating. Generate broadly, screen
hard, present few.

| Mode | Description | Strength | Cost |
|---|---|---|---|
| Descriptive | Says what it does — *General Motors*, *PayPal* | Instant comprehension | Hard to trademark, hard to outgrow |
| Suggestive | Evokes a quality — *Slack*, *Stripe*, *Amazon* | Room to grow, ownable | Needs explanation early on |
| Coined | Invented — *Kodak*, *Xerox*, *Verizon* | Fully ownable, clean domain | Expensive to build meaning into |
| Arbitrary | Real word, unrelated — *Apple*, *Monzo* | Distinctive, memorable | No inherent meaning at all |
| Compound | Two words fused — *Facebook*, *Netflix* | Balances meaning and ownability | Can feel dated fast |

For early-stage companies with small marketing budgets, suggestive usually beats
coined — you can't afford to teach the market what a made-up word means.

## Techniques

- **Root mining** — Latin, Greek, and other language roots for the core concept.
- **Metaphor** — what else in the world does what this does?
- **Analogous transfer** — words from an adjacent domain (sailing, geology, music).
- **Truncation and blends** — clip and recombine real words.
- **Founder or place** — carries authenticity, limits exit and expansion.

Generate at least 40 before filtering. The good ones rarely appear in the first ten.

## Screening

Every candidate passes all of these before it's presented. Kill silently; don't
show the user a name you already know is dead.

1. **Say it out loud** — over a phone, in a noisy room. Does it survive?
2. **Spell-after-hearing** — could someone type it correctly having only heard it?
   Failures here cost real traffic forever.
3. **Length** — under three syllables where possible. Long names get abbreviated
   by users, and you don't control the abbreviation.
4. **Domain** — exact `.com` if the budget allows; a clean alternative TLD if not.
   Note availability status for each candidate.
5. **Trademark sanity** — search the relevant registry for the target class. Look
   for existing marks in the *same class*, not just identical strings. Flag anything
   close and state plainly that this is not legal clearance and the user needs
   a trademark attorney before committing.
6. **Social handles** — consistent availability across the platforms that matter.
7. **Cross-language** — check meaning and phonetics in the languages of target
   markets. Also check unfortunate readings when the name is lowercased,
   run together as a domain, or truncated.
8. **Category collision** — does it sound like an existing competitor?
9. **Search results** — does the word already have a dominant meaning that will
   bury the brand?

## Presenting

Show three to five, never twenty. For each: the name, its mode, what it signals,
availability status, and the honest risk. Rank them. State your pick and why.

Include one deliberately uncomfortable option. The safest name in a set is rarely
the best one, and its presence makes the safe options easier to evaluate honestly.
