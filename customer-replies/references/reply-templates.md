# תבניות תשובה

מקור: dangogit/support-agent-kit (MIT), הותאם ל-[שם העסק]. התבניות הן מבנה —
הניסוח מותאם לקול העסק (writing-style כשמותקנת).

## עברית

### תבנית 1 — תשובה רגילה עם אבחון

```
היי [שם],

קיבלנו את הפנייה שלך, בדקנו ומצאנו ש[מה שמצאנו].

[הצעד הבא או ההסבר].

אם משהו לא ברור, כתוב/י לנו.

בברכה,
צוות [שם העסק]
```

### תבנית 2 — בקשת מידע נוסף

```
היי [שם],

בשביל לבדוק מה קורה, נצטרך שתשלח/י:
1. את כתובת המייל שאיתה נרשמת
2. צילום מסך של מה שאת/ה רואה

ברגע שיגיע נחזור אליך.

בברכה,
צוות [שם העסק]
```

### תבנית 3 — העברה לטיפול ידני (כסף / משפטי / תלונה קשה)

```
היי [שם],

קיבלנו את הפנייה. מישהו מהצוות יחזור אליך בקרוב בנוגע ל[הנושא].

אם יש עוד פרטים שרלוונטיים, אפשר לצרף אותם כאן בתשובה.

בברכה,
צוות [שם העסק]
```

## English

Structure: acknowledge (1 sentence) → what you found (1-2) → next step
(actionable) → offer further help.

```
Hi [Name],

Thanks for reaching out! I checked your account and [what you found].

[Concrete next step or explanation].

Let me know if you need anything else!

Best,
The [שם העסק] Team
```

## כללים חוצי-שפה

- אין קווים מפרידים ארוכים (—); פסיקים, מקפים רגילים או נקודה-פסיק.
- מקסימום סימן קריאה אחד לתשובה.
- לעולם לא מאשימים את הלקוח.
- לא ממליצים על פתרונות של מתחרים.
