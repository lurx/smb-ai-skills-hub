Claude Code הוא הדרך שבה אתם מדברים עם Claude על העסק שלכם. האפליקציה מציגה ומסדרת; Claude Code הוא המקום שבו העבודה קורית. הוא רץ בתוך VS Code כתוסף, ואפשר גם להריץ אותו מהטרמינל.

## צעד 1: לפתוח בתיקיית העבודה

הכלל החשוב ביותר: Claude Code צריך להיפתח **בתיקיית העבודה** (ברירת המחדל: `AgenticOS` בתיקיית הבית). שם נמצאים המוח העסקי, הסוכנים והזיכרון, ורק ככה Claude מכיר אותם.

- **ב-VS Code**: קובץ ← פתיחת תיקייה ← בוחרים את תיקיית העבודה. אחר כך לוחצים על אייקון Claude בסרגל הצד.
- **מהאפליקציה**: כל כפתור "פתיחת טרמינל" פותח טרמינל כבר בתיקייה הנכונה. מקלידים `claude` ולוחצים Enter.

> 📷 **צילום מסך חסר:** VS Code עם תיקיית העבודה פתוחה ופאנל Claude Code בצד.

## צעד 2: לדבר

כותבים בעברית, בשפה חופשית. כמה דוגמאות שעובדות:

```
קמי, תכיני תוכנית קמפיין לחודש הבא
אמיליה, מה היה במייל היום?
תסביר לי מה כתוב במוח העסקי
לא נכון, אצלנו לא מבטיחים תוצאות. תתקני
```

פנייה בשם של סוכן מפעילה אותו. בלי שם, Claude עונה בעצמו ומשתמש במוח העסקי.

## דברים שכדאי לדעת

- **Claude מבקש אישור לפעולות.** לפני שהוא מריץ פקודה או משנה קובץ מחוץ למה שהוגדר, הוא שואל. "כן" מאשר. אם זה מעייף, המדריך **הרשאות Bypass Permissions** מסביר איך מרחיבים את ההרשאות, על אחריותכם.
- **שיחה חדשה מנקה את הזיכרון הקצר.** מה שלא נשמר לקובץ (תוצר, זיכרון, המוח) נעלם בסוף השיחה. לכן הסוכנים כותבים תוצרים לקבצים, ולכן יש לולאת למידה.
- **פקודות עם קו נטוי** הן קיצורים: `/clear` מתחיל שיחה נקייה, `/help` מציג עזרה. לא חייבים אותן.
- **מיומנות** היא הוראות מוכנות שClaude מפעיל כשהמשימה מתאימה. אתם לא צריכים לקרוא להן בשם; מספיק לתאר מה רוצים.

## מה Claude לא עושה מעצמו

לא שולח מיילים, לא מפרסם, לא משנה קמפיינים. הוא מכין, ואתם מאשרים (ראו **תור אישורים**). לא מוחק קבצים בלי לשאול. לא נוגע במחשב מחוץ לתיקיית העבודה בלי לומר מה הוא עומד לעשות.
