כל מה שהסוכנים יודעים ועשו נמצא בתיקיית העבודה. לגבות אותה זה לגבות הכול.

## גיבוי

תיקיית העבודה היא תיקייה רגילה (ברירת מחדל: `AgenticOS` בתיקיית הבית). כל כלי גיבוי שמגבה את תיקיית הבית מגבה אותה: Time Machine, OneDrive, Google Drive לשולחן העבודה. אפשר גם להעתיק אותה ידנית לכונן חיצוני.

מה **לא** נמצא בתיקייה ולכן לא מגובה איתה: המפתחות (מחזיק המפתחות של המערכת) והגדרות האפליקציה. את המפתחות פשוט מדביקים שוב במחשב חדש.

## העברה למחשב אחר

1. מתקינים במחשב החדש את VS Code, Claude Code והאפליקציה.
2. מעתיקים את תיקיית העבודה למקום המקביל (או לכל מקום).
3. באפליקציה: **הגדרות ← עבודה ← בחירת תיקייה** ובוחרים את התיקייה שהעתקתם.
4. מסך ההגדרה הראשונית יראה מה חסר במחשב החדש: לרוב "הסביבה של Claude" ולולאת הלמידה, כי הן מותקנות במחשב ולא בתיקייה. מריצים אותן שוב.
5. מדביקים מחדש מפתחות במסך החיבורים.

## יותר מעסק אחד

לכל עסק תיקיית עבודה משלו, למשל `AgenticOS-מספרה` ו-`AgenticOS-חנות`. מחליפים ביניהן ב**הגדרות ← עבודה ← בחירת תיקייה**. האפליקציה מציגה תמיד עסק אחד; Claude Code עובד על התיקייה שפתוחה בו.

שימו לב שלולאת הלמידה מותקנת לתיקייה מסוימת. לעסק שני מתקינים אותה שוב מתוך התיקייה שלו.

## שחזור סוכן שהוסר

הסרת סוכן מעבירה את התיקייה שלו ל-`agents/.removed` עם חותמת זמן. כדי לשחזר את הזיכרון שלו: מתקינים את הסוכן מחדש מהגלריה, ומעתיקים את תיקיית `memory` מהארכיון לתיקייה החדשה. אפשר לבקש מ-Claude לעשות את זה.
