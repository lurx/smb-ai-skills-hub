מיומנויות של תוכן ומודעות (קרוסלות, קריאייטיב למודעות) יכולות להוסיף לכל שקף תמונת רקע שנוצרת ב-AI. בשביל זה צריך מפתח של Google Gemini. **בלי מפתח הכול עובד**: הקרוסלות מרונדרות כעיצוב טקסטואלי.

## מה זה עולה

אין מסלול חינמי ליצירת תמונות. נדרשת טעינת קרדיט מראש, מינימום בערך $10, שמספיקה למאה שקפים ויותר (בערך $0.05 עד $0.15 לתמונה). המפתח והחיוב בחשבון Google של העסק, לא שלנו.

## צעד 1: לפתוח AI Studio

נכנסים ל-aistudio.google.com עם חשבון Google של העסק.

> 📷 **צילום מסך חסר:** מסך הבית של Google AI Studio אחרי התחברות, עם הכפתור Get API key בסרגל.

## צעד 2: ליצור מפתח

לוחצים **Get API key** ואז **Create API key**. המפתח מוצג פעם אחת; מעתיקים אותו.

> 📷 **צילום מסך חסר:** חלון Create API key עם המפתח שנוצר (לטשטש את הערך).

## צעד 3: להפעיל חיוב

בלוח הבקרה בוחרים **Billing**, מוסיפים אמצעי תשלום וטוענים קרדיט. המסך באנגלית; הסדר הוא אמצעי תשלום, סכום, אישור.

> 📷 **צילום מסך חסר:** מסך Billing עם אפשרות טעינת קרדיט.

## צעד 4: להדביק באפליקציה

**הגדרות ← אבטחה ← Google Gemini**: מדביקים את המפתח ולוחצים **שמירה**. המפתח נשמר במחזיק המפתחות של המחשב. אף פעם לא לשלוח אותו במייל ולא לשמור בקובץ משותף.

## כשנגמר הקרדיט

הסוכן מזהה זאת ומודיע בעברית. טוענים שוב ב-aistudio.google.com ← Billing. היתרה הקובעת היא זו שמופיעה ב-Dashboard ← Usage and Limits; לפעמים יש עיכוב בסנכרון, ומה שכתוב שם קובע.
