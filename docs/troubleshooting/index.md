## מסך ההגדרה

**שורה לא עוברת ל"הושלם" אחרי שClaude סיים.**
האפליקציה בודקת קבצים בתיקיית העבודה. ודאו ש-Claude Code רץ **בתיקיית העבודה** ולא בתיקייה אחרת (ראו **Claude Code למי שלא מתכנת**). אם הריצה הייתה בתיקייה הנכונה, פתיחה מחדש של מסך ההגדרה מרעננת.

**בווינדוס: "running scripts is disabled on this system" או שגיאת execution policy.**
תיקון חד-פעמי. פותחים PowerShell ומריצים:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
```

סוגרים ופותחים את הטרמינל מחדש, ומדביקים את הפקודה שוב.

**בווינדוס: "claude is not recognized".**
Claude Code מותקן אבל לא בנתיב. פקודת "הסביבה של Claude" מוסיפה את הנתיב; אם עוד לא הרצתם אותה, סוגרים את הטרמינל, פותחים חדש, ומנסים שוב. אם עדיין לא, מריצים את ההתקנה של Claude Code מחדש.

**"התשובות השתנו מאז הבנייה האחרונה" לא נעלם.**
בונים מחדש (שורת המוח העסקי). ההודעה נעלמת כשהבנייה מסתיימת וכותבת את הקובץ.

## Claude

**"Claude מחובר" בסרגל העליון, אבל Claude מבקש להתחבר בטרמינל.**
הסימון בסרגל בודק שClaude Code מותקן, לא שהוא מחובר. בטרמינל מריצים `claude login` פעם אחת.

**Claude לא מזהה את הסוכן ("מי זה קמי?").**
או שהסוכן לא מותקן (בודקים במרכז הפיקוד), או שClaude פתוח בתיקייה אחרת.

**Claude מבקש אישור על כל דבר.**
זו ההתנהגות הבטוחה. המדריך **הרשאות Bypass Permissions** מסביר איך מרחיבים.

## מעקב מודעות

**הדשבורד לא נטען, או "דשבורד המודעות לא רץ".**
הדשבורד הוא תהליך שהאפליקציה מפעילה בעצמה. סוגרים את האפליקציה לגמרי (במק: Cmd+Q) ופותחים מחדש. אם עדיין לא, בודקים שתוכנה אחרת לא תופסת את פורט 3055.

**"החיבור נכשל" אחרי הדבקת טוקן.**
ראו **מעקב מודעות: הדשבורד**.

## חיבורים

**Gmail מציג "עדיין לא זוהה שימוש" למרות שחיברתם.**
החיבור הוא ל-Claude, והאפליקציה מזהה אותו רק אחרי שClaude באמת קרא מהמייל. בקשו משהו מהמייל בשיחה בתיקיית העבודה.

**מפתח שהדבקתם לא נשמר.**
המפתח חייב להיות שורה אחת בלי רווחים מיותרים. אם המחשב שואל על גישה למחזיק המפתחות, מאשרים.

## עזרה ומדריכים

**"אין חיבור למאגר המדריכים".**
המדריכים שהגיעו עם האפליקציה מוצגים. עדכונים נמשכים כשיש אינטרנט. אפשר לכבות את המשיכה ב**הגדרות ← העדפות ← עדכון מדריכים**.

## כשכלום לא עוזר

סוגרים את האפליקציה לגמרי ופותחים מחדש. תיקיית העבודה נשארת כמו שהיא: שום דבר שנעשה לא הולך לאיבוד בסגירה. אם הבעיה חוזרת, ראו **מדריך לבודקי האלפא** לאיסוף המידע שעוזר לנו לתקן.
