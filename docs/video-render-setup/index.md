הסוכן של התוכן (קופי) מרנדר קרוסלות לאינסטגרם ולפייסבוק עם **Remotion**, כלי חינמי לעסקים עד שלושה עובדים, בלי הרשמה ובלי מפתח. הרינדור עצמו קורה במחשב שלכם.

## חלק 1: Node (חובה, חינם)

Remotion צריך Node גרסה 18 ומעלה.

- **בווינדוס**: פותחים טרמינל ומריצים `winget install OpenJS.NodeJS.LTS`.
- **במק**: `brew install node` (אם אין Homebrew, מורידים מ-nodejs.org).

בודקים: `node --version` צריך להחזיר מספר.

את פרויקט ה-Remotion של הקרוסלות הסוכן מקים בעצמו בתיקיית העבודה בפעם הראשונה שמבקשים קרוסלה. אין התקנה ידנית נוספת.

> 📷 **צילום מסך חסר:** טרמינל אחרי `node --version` עם מספר גרסה.

## חלק 2: מפתח Gemini (אופציונלי, בתשלום)

בלי מפתח, הקרוסלות מרונדרות כעיצוב טקסטואלי. עם מפתח, כל שקף מקבל תמונת רקע שנוצרת ב-AI, בערך $0.5 עד $1.5 לקרוסלה מלאה. ראו **מפתח Gemini ליצירת תמונות**.

## איך זה עובד בפועל

```
קופי, תכיני קרוסלה על שלושת הטיפים לטיפוח שיער בקיץ
```

הסוכן כותב את הטקסטים, מעצב, מרנדר לתמונות, ושם את התוצר בתיקיית התוצרים. הוא לא מפרסם: הפרסום נשאר אצלכם, אחרי שראיתם.

## אם הרינדור נכשל

- **"node: command not found"**: Node לא מותקן או שהטרמינל נפתח לפני ההתקנה. סוגרים ופותחים טרמינל חדש.
- **הרינדור רץ הרבה זמן**: הפעם הראשונה מתקינה חבילות ויכולה לקחת כמה דקות. בפעמים הבאות זה מהיר.
- **התמונות לא נוצרו אבל הטקסט כן**: נגמר הקרדיט של Gemini, או שאין מפתח. הסוכן אמור לומר איזה משניהם.
