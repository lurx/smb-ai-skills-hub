| מונח | מה זה |
| --- | --- |
| **Claude** | המודל של Anthropic. עובד במנוי שלכם. |
| **Claude Code** | הכלי שבו מדברים עם Claude על קבצים ותיקיות. תוסף ל-VS Code, וגם פקודה בטרמינל. |
| **VS Code** | העורך החינמי שבו רץ Claude Code. |
| **תיקיית העבודה** | התיקייה שבה חי כל מה שקשור לעסק: המוח, הסוכנים, הזיכרון, התוצרים. |
| **המוח העסקי** | קובץ `business/CLAUDE.md` שכל סוכן קורא לפני משימה. נבנה מהשאלון. |
| **השאלון** | עשרה חלקים קצרים על העסק, באפליקציה. המקור למוח. |
| **סוכן (עובד)** | הוראות ומיומנויות לתפקיד מסוים, עם שם חיבה. מופעל ב-Claude Code בפנייה בשם. |
| **מיומנות (Skill)** | הוראות מוכנות למשימה מסוימת, שClaude מפעיל כשהמשימה מתאימה. |
| **מאגר המיומנויות (Skills Hub)** | האוסף הציבורי שלנו של מיומנויות. חלקן מגיעות עם סוכנים. |
| **תוצר** | קובץ שסוכן הכין: טיוטת מייל, תוכנית, קרוסלה. נשמר בתיקיית התוצרים. |
| **אישור** | סימון שלכם ביומן שתוצר מאושר. שום דבר לא יוצא בלי זה. |
| **יומן פעילות** | סיכום של כל ריצה של סוכן: מה נעשה, אילו תוצרים, האם נדרש אישור. |
| **זיכרון** | כללים שסוכן למד, קובץ לכל כלל, בתיקיית הסוכן. |
| **לולאת הלמידה** | ריצה יומית שהופכת תיקונים בשיחה לזיכרון. |
| **חיבור** | גישה של סוכן לשירות חיצוני: Gmail, רב מסר, Meta. |
| **מפתח / טוקן** | מחרוזת סודית שמזהה אתכם מול שירות. נשמרת במחזיק המפתחות של המחשב. |
| **MCP** | הדרך שבה Claude מדבר עם שירות חיצוני (מייל, דיוור). לרוב לא צריך לדעת עליו. |
| **טרמינל** | חלון פקודות. האפליקציה פותחת אותו בשבילכם בתיקייה הנכונה. |
| **RTL** | טקסט מימין לשמאל. תוסף קטן ל-VS Code שמסדר את זה. |
| **גרסת אלפא** | הגרסה הנוכחית: מלאה, עם כלי בדיקה, ועם דברים שעוד ישתנו. |
