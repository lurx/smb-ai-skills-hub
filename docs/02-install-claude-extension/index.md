הסוכנים רצים בתוך **Claude Code**, שמגיע כתוסף לעורך **VS Code** (חינמי, של מיקרוסופט). ההתקנה לוקחת כעשר דקות ועושים אותה פעם אחת. אם כבר יש לכם VS Code עם Claude Code, דלגו לצעד 4.

## צעד 1: התקנת VS Code

1. נכנסים ל-code.visualstudio.com ולוחצים **Download**. האתר מזהה אם אתם במק או בווינדוס.
2. **במק**: פותחים את קובץ ה-zip וגוררים את VS Code לתיקיית Applications.
3. **בווינדוס**: מריצים את קובץ ההתקנה ולוחצים "הבא" עד הסוף. משאירים מסומן את "Add to PATH".

> 📷 **צילום מסך חסר:** דף ההורדה של VS Code עם כפתור Download.

## צעד 2: התקנת תוסף Claude Code

1. פותחים VS Code.
2. לוחצים על אייקון **Extensions** בסרגל הצד (ארבעה ריבועים), או Ctrl+Shift+X (במק: Cmd+Shift+X).
3. מחפשים `Claude Code` ומתקינים את התוסף הרשמי של **Anthropic**. לחיצה על **Install**.

> 📷 **צילום מסך חסר:** חלון ה-Extensions עם תוסף Claude Code של Anthropic ותוצאת החיפוש.

אחרי ההתקנה מופיע אייקון Claude בסרגל הצד.

## צעד 3: התחברות למנוי

1. לוחצים על אייקון Claude. בפעם הראשונה הוא מציע להתחבר.
2. נפתח דפדפן עם ההתחברות לחשבון Claude שלכם. מתחברים ומאשרים. צריך מנוי Claude Pro או Max; המנוי הוא שלכם, ואיתו הסוכנים עובדים.
3. חוזרים ל-VS Code. הפאנל של Claude מוכן לשיחה.

> 📷 **צילום מסך חסר:** פאנל Claude Code ב-VS Code אחרי ההתחברות, עם שדה ההודעה.

## צעד 4: לפתוח בתיקיית העבודה

VS Code עובד על תיקייה. **קובץ ← פתיחת תיקייה** ובוחרים את תיקיית העבודה שיצרתם באפליקציה (ברירת המחדל: `AgenticOS` בתיקיית הבית). מהרגע הזה Claude רואה את המוח העסקי ואת הסוכנים.

אפשר להשאיר את VS Code פתוח על התיקייה הזו לתמיד. כל כפתור "פתיחת טרמינל" באפליקציה פותח טרמינל באותה תיקייה בדיוק.

## מה הלאה

- **הרשאות Bypass Permissions**: כדי שClaude יריץ פקודות בלי לשאול על כל אחת.
- **התקנת תוסף עברית RTL**: כדי שהטקסט בפאנל יוצג מימין לשמאל. פקודת "הסביבה של Claude" באפליקציה מתקינה אותו בשבילכם.
